Steps: IMX8MM Board Bring-up, Embedded Artist(EA) = Base board and developer board are from EA
1. Build the tool chain in the PC using YOCTO Recipie - https://confluencewikiprod.intra.infineon.com/spaces/CA/pages/3456247979/HOW+TO+Build+ARM+toolchain+for+Embedded+Artists+IMX8MQ+Board+using+Yocto
2. Using Yocto Recipie we build the toolchain. Tool Chain is native build and whoch is building the cross compiler = i.e. we are making a cross compiler since we dont have cross compiler for IMx (.bb file Bitbake file = Make file = recipie file)
3. via crosscompilation
4. Install the crosscompiler = toolchain in the PC
5. Clone linux source IMX - kernel source code from online linux iMX repo - https://confluencewikiprod.intra.infineon.com/spaces/CA/pages/3009337952/iMX8M+mini+bringup+Flashing+FMAC
6. Setup the build environment
	environment ? Set FLAGS like COmpile Flags, or Set Architecture ARM64 or 
7. Build the Kernel (Make) after making changes in the .config of Kenrnel
	.config = Kernel inbuild drivers selection, 32bit or 64bit kernel,
8. Ater building we will get image at arch/arm64/boot/image 
9. UUU tool to flash the image - http://imx.embeddedartists.com/ - The site has bootloader, dafult kernel and other file system images, dtb files, boot script, deault rootfs directory etc.. for a particular version image and the board
10. Connect USB cable to IMX board, Jumper cnnection set-up for Boot mode,->reboot -> now in boot mode. Now our IMX device will pop like USB storage device
11. uuu.exe file from our PC execute => sends/ copies all files in step 9 (downloaded files) to IMX device along with image
